## Overview

The purpose of a dropdown search is to provide a compact and organised way to display a set of selectable items, such as categories, filters, or actions, within a user interface.

Dropdowns enhance user experience by conserving screen space, organising choices in a structured manner, and allowing users to quickly search for and access specific options. The search functionality makes it convenient for users to efficiently find and select from a wide range of options.
